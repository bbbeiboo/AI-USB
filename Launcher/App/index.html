API 配置

API Key 将加密保存在当前 Windows 用户环境（DPAPI），不会写入 U 盘配置文件，也不会随 U 盘复制到其他电脑。
「验证连接」会向 Provider 发送 1 次真实请求（GET /models，不进行模型推理），不自动重试。
「拉取模型」= 1 次 GET 模型列表（10 秒超时）；「测试连接」= 1 次 POST Responses 请求（15 秒超时），两者都不会自动重试；输入框留空时使用已保存的密钥。
